# Images

Drop images here and they'll appear automatically on the site. Filenames the app expects:

## Home (`/`)
- `avatar-1.jpg` … `avatar-4.jpg` — small trust-strip avatars
- `hero-speaking.jpg` — Owais speaking (hero card)
- `hero-side.jpg` — second hero card

## About (`/about`)
- `gallery-1.jpg` … `gallery-17.jpg` — speaking/highlights gallery

## Awards (`/awards`)
- `award-1.png` … `award-10.png`
- `cert-1.png` … `cert-12.png`
- `testimonial-huzaifa.jpg`, `testimonial-zeeshan.jpg`, `testimonial-zahid.jpg`,
  `testimonial-ahmed.jpg`, `testimonial-ushna.jpg`, `testimonial-hamza.jpg`

## Podcast (`/podcast`)
- `podcast-<youtube-id>.jpg` — thumbnail per video (optional; falls back to a color card)

Any missing file renders as a colored placeholder so nothing breaks.
